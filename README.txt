HAVEN REAL ESTATE WEBSITE

Files:
- index.html: property listing page, sample listings, contact links and favorite-button demo
- style.css: responsive website styling

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

Notes:
- Property images are loaded from Unsplash and require an internet connection.
- Listings, prices, phone number and email are sample/demo content. Replace them with verified business details.
- Search form is a front-end demo that jumps to listings; connect it to a backend for real filtering.
